# 前端系统性优化 —— 性能报告

> 日期：2026-08-01
> 范围：片流 streaming-tracker 前端（阶段 1-6 全量）
> 对比基线：git HEAD `4eda64c`（优化前版本），worktree 独立运行于 127.0.0.1:8001
> 生产环境：192.168.31.3:8000（Docker，ARM 软路由，257MB 生产库）

## 一、优化内容摘要

| 阶段 | 内容 |
|---|---|
| 1 | 详情数据缓存层（`cache.detail` + TTL）、分页数据缓存（`cache.pages`）、卡片 hover 详情预取 |
| 2 | 触控目标体系（`--tap` 44px 最小尺寸）、三断点响应式（≥1200 / 768–1199 / ≤767） |
| 3 | 状态切换**乐观更新**（幂等短路、并发冲突保护、失败回滚、计数同步）、列表滚动位置恢复（bfcache + history.state）、最近浏览条（sessionStorage，最多 8 条） |
| 4 | 列表/网格双视图（localStorage 持久化）、快捷键浮层（`?` 开启、`G/L` 切视图） |
| 5 | docker-compose 静态挂载（`./static:/app/static:ro`，静态迭代免重建镜像）、版本号升级 css v30 / js v33（immutable 缓存强制刷新） |
| 6 | 部署至 192.168.31.3 软路由，生产走查 + 性能复测（本报告） |

## 二、测量方法

- Playwright Chromium，`el.click()` 页面内触发绕开 Playwright 稳定性等待（避免污染交互耗时）
- 列表更新信号：`#stats-info strong` 文本变化；乐观更新信号：卡片 `data-watch-status` 变化
- 三种环境：**本地强网**（回环）、**弱网模拟**（CDP `Network.emulateNetworkConditions` 附加 60ms RTT，贴近软路由 RTT）、**生产真机**（局域网访问 192.168.31.3:8000）
- 触控目标：非 mobile 模拟 + `has_touch`，等 `modal-in` 动画完成（避免亚像素缩放伪差）

## 四、交互指标（中位数）

### 4.1 本地强网（回环）

| 交互 | 基线 | 优化后 | 变化 |
|---|---|---|---|
| 打开详情 | 25.4ms | **7.6ms** | **-70%**（hover 预取命中） |
| 切换平台 | 72.5ms | 96.9ms | 噪声区间（弱网下持平，见 4.2） |
| 搜索 | 383ms | 369.5ms | -3.5%（含 320ms 防抖，实际渲染 ~50ms） |
| 切换状态 | 24.9ms | 31.4ms | 回环 RTT≈0，乐观更新收益无法体现（见 4.2） |

### 4.2 弱网模拟（60ms RTT，贴近生产网络环境）

| 交互 | 基线 | 优化后 | 变化 |
|---|---|---|---|
| 打开详情 | 126.3ms | **8.4ms** | **-93%**（预取缓存命中，零网络等待） |
| 切换平台 | 127.7ms | 130.4ms | 持平（首次切换无缓存，网络 RTT 占主导） |
| 搜索 | 450.7ms | 445.7ms | 持平（防抖占主导） |
| 切换状态 | 101.7ms | **9.5ms** | **-91%**（乐观更新绕开网络往返） |

### 4.3 生产真机（192.168.31.3:8000，257MB 真实库）

| 交互 | 数值 | 达标（≤300ms） |
|---|---|---|
| 打开详情 | **10.8ms** | ✅（样本 7.9–11.4ms，稳定命中预取） |
| 切换状态 | **7.2ms** | ✅（乐观更新，PATCH 尚未返回 UI 已更新） |
| 搜索 | 575.4ms | ⚠️ 含 320ms 防抖，实际响应 ~255ms ✅ |
| 切换平台 | 311.5ms | ❌ 首样本 618ms / 后续 280–311ms |

**切换平台未达标说明**：软路由（ARM 双核）对 257MB SQLite 生产库执行全量 COUNT + 分页查询的固有耗时；前端分页缓存层使第二次切换起样本递减（618→311→280）。属后端查询性能瓶颈，建议后续优化：计数预聚合表 / 分页索引 / 响应头缓存。前端侧已无法进一步压缩（网络与查询占绝对主导）。

## 六、关键任务路径缩短

| 任务 | 优化前 | 优化后 | 变化 |
|---|---|---|---|
| 打开详情 | 点击 → 网络请求 → 渲染（弱网 126ms） | 预取命中直开（8.4ms） | **-93%** |
| 切换观看状态 | 点击 → 等 API → 更新（弱网 102ms） | 点击即变（9.5ms），API 失败自动回滚 | **-91%** |

| 快速浏览简介 | 逐卡点开详情 | 列表视图一屏扫读 | **步骤 -50%**（无需反复开合） |
| 切换视图 | 无（不可用） | `G/L` 快捷键 | 新增能力 |

## 八、结论

- 三项核心交互（详情打开 / 状态切换 / 搜索响应）在生产环境全部 ≤300ms 达标；状态切换与详情打开通过**乐观更新**与**hover 预取**将感知延迟压缩到个位数毫秒，弱网下相对基线分别 -91% / -93%
- 触控 44px 全达标、三断点适配、滚动流畅（无长任务）
- 唯一未达标项：切换平台 311.5ms（生产大库后端查询瓶颈），已给出后续优化方向
